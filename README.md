# Kabbalah na TV

Aulas de Kabbalah em português com conteúdo diário.

Site estático puro (HTML, CSS e JS, sem build).

## Publicado

https://kabbalahnatv.densyy.com

## Como usar localmente

Opção 1 — abrir direto:

```sh
xdg-open index.html
```

Opção 2 — servidor estático (na raiz do projeto):

```sh
python3 -m http.server 8080
```

Abrir http://localhost:8080 no navegador.

## Estrutura

```text
index.html
CNAME
assets/css/index.css
assets/js/index.js
assets/img/shared.jpg
assets/img/favicon/
```

Idioma: pt-BR. Publicação via CNAME `kabbalahnatv.densyy.com`.
